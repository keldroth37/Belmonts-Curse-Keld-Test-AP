Castlevania: Belmont's Curse - Archipelago
==========================================

What's in here
  belmonts_curse.apworld              the game's Archipelago world (for whoever generates/hosts)
  Castlevania Belmont's Curse.yaml    player settings template
  BelmontsCurseAP-Setup.exe           installs the in-game client (Windows)

Generating a game (host)
  1. Double-click belmonts_curse.apworld (or copy it into Archipelago's "custom_worlds" folder).
     Needs Archipelago 0.6.4 or newer.
  2. Each player edits the .yaml (at least "name") and puts it in Archipelago's "Players" folder.
  3. Generate as usual and host the game (archipelago.gg or your own server).

Playing
  1. Close the game. Run BelmontsCurseAP-Setup.exe. It finds the Steam install (or click Browse and pick the
     "Castlevania Belmont's Curse" folder), downloads BepInEx 6 (the mod loader) and installs the client.
  2. Start the game. The first start with BepInEx takes a few minutes; a console window may appear.
  3. Press F1 in game: enter the server address (e.g. archipelago.gg:12345), your slot name and password, Connect.
  4. Start a NEW game for a new seed.

In-game keys
  F1  Archipelago window: connect, warp to any used mirror, re-give missing items, debug options
  F6  skip the cutscene that is playing          F9  why a room isn't 100% on the map
  On the map: hover a used mirror and press T to warp there (after closing the map), or use the mirror list.

Good to know
  - Items from the multiworld show up as a banner; checks are sent when you pick things up.
  - Intro cutscenes are skipped automatically (toggle in F1).
  - The win is sent automatically when your goal's ending scene starts.
  - Kneeling into the Hall of Mirrors is an item ("Mirror Kneel"), found somewhere in the multiworld.

Uninstall: run BelmontsCurseAP-Setup.exe and click Uninstall.
